变更 5耗材使用登记 · 检索页（新设计）

变更说明（对照原「术前交接」样式）

① 首页：第 8 格「静配核对」移除，新增「耗材核销」入口，图标位、配色、卡片样式与原九宫格完全一致。
② 扫码页：沿用「手术交接」扫码页结构（顶部蓝条 + 手机扫码插画 + 点击扫码按钮），支持扫患者腕带或耗材标签两种入口。
③ 患者列表页：沿用「手术交接(3)」卡片版式，「申请时间」调整为「领用时间」，状态由「待转接 / 已转接」改为「待核销 / 已核销」。
④ 核销详情页：本次新增设计。展示患者信息与已扫耗材明细（名称 / 批号 / 效期 / 使用与实际数量），区分「可收费（关联患者计费）」与「不可收费（科室消耗登记）」，底部「确认核销」提交后回写二级库台账，形成闭环。本页新增「＋ 手动增加登记」入口：点按自下而上调起「使用登记检索界面」（屏 5），在该界面选定耗材后点「完成」即回填至本页核销清单（已预置一条「✎ 手动添加」示例项），实现两界面的数据联动。
⑤ 使用登记检索页：本次新增设计。顶部检索框支持按耗材名称 / 编码查询；两个标签可在「可收费项目（关联患者计费）」与「科室消耗项目（按科室消耗登记）」之间切换，逐条「+ 加入登记」后底部「确认登记」汇总提交。覆盖需求清单中「使用登记模块」可收费 / 不可收费的分类登记口径。
⑥ 误扫退回（V1.1 新增）：针对「已扫描但尚未核销 / 计费」的耗材，在核销详情每条耗材下方提供「↩ 误扫退回」入口，点按调起底部抽屉，按包装状态分为两种处理——①包装完好 · 可退回库存：撤销本条扫描记录 ＋ 库存回冲，不计损耗；②包装破损 · 无法退回库存：库存不予回冲，登记为科室损耗，并须选择损耗原因（包装破损 / 漏气失效、已拆封无法复原、拆封后污染、质量故障、其他）。因退回发生在计费之前，两条路径均不涉及患者费用冲销；已计费耗材的冲销另走「退库 / 退费」流程。
⑦ 损耗登记（V1.2 新增）：解决「一个耗材只能收患者一次费用、但护士操作失误会产生损耗」的场景。每条可收费耗材新增「使用 / 实际 / 损耗」三个可改数量，满足 使用 = 实际 + 损耗；损耗部分不计患者费用，计入科室报损。当损耗 > 0 时出现橙色「损耗原因」模块，下拉选择预设原因（穿刺 / 置管失败、针头 / 导管污染、包装破损 / 漏气失效、器械质量故障、患者拒绝 / 操作中止、误取 / 重复取用），仅选「其他（请填写）」时才展开文本框手填，减少护士输入。不可收费（科室消耗）条目本身即由科室吸收，不设损耗登记；屏内汇总栏同步显示「损耗 N 支（不计费）」。
