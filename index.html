闭环管理流程（PDCA）

P · 上报登记

按「指标类别 → 环节 → 指标名称」三级定位，24h 内完成上报；系统自动生成事件编号。

D · 应急处置

封存 / 召回 / 停用设备 / 重处理，通知使用科室，涉及患者启动随访。

C · 原因分析

鱼骨图 + 5Why 定位根因，核查同批次、同设备、同班次风险面，质控员复核。

A · 整改归档

措施落地 + 复检验证，结局归档支持上传整改凭证图片，纳入月度质控分析会。
